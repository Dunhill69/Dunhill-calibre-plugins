# Calibre Updater

**Versión / Version:** 1.23.6 · **calibre mínimo / minimum calibre:** 7.0.0 · **Sistemas / Platforms:** Windows, macOS, Linux

**Idioma de la interfaz / Interface language:** Inglés, español y 17 idiomas más / English, Spanish and 17 more languages

## Español

Avisa cuando hay una nueva versión de calibre y la instala por el método oficial en Linux, Windows y macOS.

### Instalación

1. Descargá el archivo `.zip` desde [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=calibre_updater).
2. En calibre: **Preferencias → Complementos → Cargar complemento desde archivo**.
3. Elegí el `.zip` y reiniciá calibre.

## English

Notifies you of new calibre versions and installs them the official way on Linux, Windows and macOS.

### Installation

1. Download the `.zip` file from [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=calibre_updater).
2. In calibre: **Preferences → Plugins → Load plugin from file**.
3. Pick the `.zip` and restart calibre.
