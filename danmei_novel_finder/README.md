# Danmei Novel Finder

**Versión / Version:** 1.2.1 · **calibre mínimo / minimum calibre:** 6.0.0 · **Sistemas / Platforms:** Windows, macOS, Linux

## Español

Explora el catálogo de danmeinovel.com y descarga novelas como EPUB (directo a la biblioteca) o TXT.

### Instalación

1. Descargá el archivo `.zip` desde [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=danmei_novel_finder).
2. En calibre: **Preferencias → Complementos → Cargar complemento desde archivo**.
3. Elegí el `.zip` y reiniciá calibre.

## English

Browses the danmeinovel.com catalog and downloads novels as EPUB (straight into the library) or TXT.

### Installation

1. Download the `.zip` file from [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=danmei_novel_finder).
2. In calibre: **Preferences → Plugins → Load plugin from file**.
3. Pick the `.zip` and restart calibre.
