# AnnasArchivePlus

**Versión / Version:** 1.3.1 · **calibre mínimo / minimum calibre:** 6.0.0 · **Sistemas / Platforms:** Windows, macOS, Linux

**Idioma de la interfaz / Interface language:** Solo español / Spanish only

> 🇪🇸 **Nota:** este complemento está pensado para usuarios hispanohablantes y su interfaz está solo en español.  
> **Note:** this plugin is aimed at Spanish speakers and its interface is in Spanish only.

## Español

Fuente de metadatos de Anna's Archive: busca por título, autor o ISBN y guarda el identificador annasarchive.

### Instalación

1. Descargá el archivo `.zip` desde [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=annas_archive_plus).
2. En calibre: **Preferencias → Complementos → Cargar complemento desde archivo**.
3. Elegí el `.zip` y reiniciá calibre.

## English

Anna's Archive metadata source: searches by title, author or ISBN and stores the annasarchive identifier.

### Installation

1. Download the `.zip` file from [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=annas_archive_plus).
2. In calibre: **Preferences → Plugins → Load plugin from file**.
3. Pick the `.zip` and restart calibre.
