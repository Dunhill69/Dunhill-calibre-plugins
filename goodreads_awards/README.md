# Goodreads Awards

**Versión / Version:** 1.2.0 · **calibre mínimo / minimum calibre:** 5.0.0 · **Sistemas / Platforms:** Windows, macOS, Linux

**Idioma de la interfaz / Interface language:** Inglés y español / English and Spanish

## Español

Busca los libros en Goodreads y guarda sus premios literarios en una columna.

### Instalación

1. Descargá el archivo `.zip` desde [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=goodreads_awards).
2. En calibre: **Preferencias → Complementos → Cargar complemento desde archivo**.
3. Elegí el `.zip` y reiniciá calibre.

## English

Looks books up on Goodreads and stores their literary awards in a column.

### Installation

1. Download the `.zip` file from [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=goodreads_awards).
2. In calibre: **Preferences → Plugins → Load plugin from file**.
3. Pick the `.zip` and restart calibre.
