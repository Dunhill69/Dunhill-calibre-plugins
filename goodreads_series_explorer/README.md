# Goodreads Series Explorer

**Versión / Version:** 1.12.0 · **calibre mínimo / minimum calibre:** 6.0.0 · **Sistemas / Platforms:** Windows, macOS, Linux

**Idioma de la interfaz / Interface language:** Inglés y español / English and Spanish

## Español

Explora en Goodreads la saga o serie completa del libro seleccionado, con los datos de las ediciones en tu idioma.

### Instalación

1. Descargá el archivo `.zip` desde [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=goodreads_series_explorer).
2. En calibre: **Preferencias → Complementos → Cargar complemento desde archivo**.
3. Elegí el `.zip` y reiniciá calibre.

## English

Explores the whole Goodreads series of the selected book, with the data of the editions in your language.

### Installation

1. Download the `.zip` file from [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=goodreads_series_explorer).
2. In calibre: **Preferences → Plugins → Load plugin from file**.
3. Pick the `.zip` and restart calibre.
