# Mylar Series Plus

**Versión / Version:** 1.1.0 · **calibre mínimo / minimum calibre:** 6.0.0 · **Sistemas / Platforms:** Windows, macOS, Linux

**Idioma de la interfaz / Interface language:** Inglés, español y 17 idiomas más / English, Spanish and 17 more languages

## Español

Crea los metadatos series.json de Mylar3 y fichas visuales de la serie en los comentarios, desde ComicVine.

### Instalación

1. Descargá el archivo `.zip` desde [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=mylar_series_plus).
2. En calibre: **Preferencias → Complementos → Cargar complemento desde archivo**.
3. Elegí el `.zip` y reiniciá calibre.

## English

Creates Mylar3 series.json metadata and visual series cards in the comments, from ComicVine.

### Installation

1. Download the `.zip` file from [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=mylar_series_plus).
2. In calibre: **Preferences → Plugins → Load plugin from file**.
3. Pick the `.zip` and restart calibre.
