# Calibre CSS

**Versión / Version:** 1.7.1 · **calibre mínimo / minimum calibre:** 7.0.0 · **Sistemas / Platforms:** Windows, macOS, Linux

**Idioma de la interfaz / Interface language:** Inglés y español / English and Spanish

## Español

Usa un estilo CSS distinto en el panel de detalles y en el visor para cada biblioteca.

### Instalación

1. Descargá el archivo `.zip` desde [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=calibre_css).
2. En calibre: **Preferencias → Complementos → Cargar complemento desde archivo**.
3. Elegí el `.zip` y reiniciá calibre.

## English

Uses a different CSS style for the book details panel and the viewer in each library.

### Installation

1. Download the `.zip` file from [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=calibre_css).
2. In calibre: **Preferences → Plugins → Load plugin from file**.
3. Pick the `.zip` and restart calibre.
