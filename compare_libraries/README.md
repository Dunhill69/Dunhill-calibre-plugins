# Compare Libraries

**Versión / Version:** 1.2.0 · **calibre mínimo / minimum calibre:** 6.0.0 · **Sistemas / Platforms:** Windows, macOS, Linux

**Idioma de la interfaz / Interface language:** Solo español / Spanish only

> 🇪🇸 **Nota:** este complemento está pensado para usuarios hispanohablantes y su interfaz está solo en español.  
> **Note:** this plugin is aimed at Spanish speakers and its interface is in Spanish only.

## Español

Compara la biblioteca actual con otra biblioteca o carpeta e importa los libros faltantes sin duplicados.

### Instalación

1. Descargá el archivo `.zip` desde [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=compare_libraries).
2. En calibre: **Preferencias → Complementos → Cargar complemento desde archivo**.
3. Elegí el `.zip` y reiniciá calibre.

## English

Compares the current library with another library or folder and imports the missing books without duplicates.

### Installation

1. Download the `.zip` file from [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=compare_libraries).
2. In calibre: **Preferences → Plugins → Load plugin from file**.
3. Pick the `.zip` and restart calibre.
