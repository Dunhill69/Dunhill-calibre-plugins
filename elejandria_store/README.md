# Elejandría

**Versión / Version:** 1.1.2 · **calibre mínimo / minimum calibre:** 6.0.0 · **Sistemas / Platforms:** Windows, macOS, Linux

## Español

Libros gratis y legales en español de elejandria.com, con descarga directa en EPUB, PDF y MOBI.

### Instalación

1. Descargá el archivo `.zip` desde [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=elejandria_store).
2. En calibre: **Preferencias → Complementos → Cargar complemento desde archivo**.
3. Elegí el `.zip` y reiniciá calibre.

## English

Free and legal Spanish books from elejandria.com, with direct EPUB, PDF and MOBI downloads.

### Installation

1. Download the `.zip` file from [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=elejandria_store).
2. In calibre: **Preferences → Plugins → Load plugin from file**.
3. Pick the `.zip` and restart calibre.
