# EPUB to XTC Converter

**Versión / Version:** 2.3.0 · **calibre mínimo / minimum calibre:** 6.0.0 · **Sistemas / Platforms:** Windows, macOS, Linux

**Idioma de la interfaz / Interface language:** Inglés y español / English and Spanish

## Español

Convierte libros al formato XTC/XTCH del lector Xteink X4, con las páginas generadas por calibre.

### Instalación

1. Descargá el archivo `.zip` desde [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=epub_to_xtc_converter).
2. En calibre: **Preferencias → Complementos → Cargar complemento desde archivo**.
3. Elegí el `.zip` y reiniciá calibre.

## English

Converts books to the XTC/XTCH format of the Xteink X4 e-reader, with pages rendered by calibre.

### Installation

1. Download the `.zip` file from [Releases](https://github.com/Dunhill69/Dunhill-calibre-plugins/releases?q=epub_to_xtc_converter).
2. In calibre: **Preferences → Plugins → Load plugin from file**.
3. Pick the `.zip` and restart calibre.
